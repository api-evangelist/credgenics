# Credgenics

> Credgenics is an AI-powered SaaS platform for debt collection and loan
> recovery, used by banks, NBFCs, housing-finance and microfinance lenders and
> fintechs (primarily in India). Its REST Recovery API lets lenders push loan,
> customer, payment and transaction data in and read collections status back,
> alongside communication, dialer, field-collection, litigation and payment
> products.

## APIs
- [Recovery API docs](https://docs.credgenics.com/#getting-started): Lending and Credit Line REST API. Base URL https://apiprod.credgenics.com. Token auth via the `authenticationtoken` header; `company_id` query parameter required on every request.
